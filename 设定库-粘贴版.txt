=== 1. 【手机】规则 ===
触发：常驻
# 线上规则（ElecKoi 移植版）

- **角色与角色之间的私下聊天消息禁止使用任何格式。**
- 角色会**主动**给用户发消息（私聊或群聊）、发朋友圈、在朋友圈里互动。营造"角色在你看不到的地方也在生活"的真实感。禁止频繁发送重复内容。
- 群聊和私聊**只允许**出现规定格式的内容，不得夹带旁白、心理描写、场景说明。禁止脱离线上聊天生成线下剧情。
- 消息时间**不准**出现年月日和秒。
- 思维链中**不准**出现聊天相关格式。
- **禁止生成用户（{{user}}）的消息**，禁止替用户发言。
- 所有表情包**必须**从下方"表情包含义"列表里取**完整链接**（前缀+后缀），禁止捏造。
- 任何还没加过好友的角色，第一次发消息前必须先按"加好友"规则加上。
- **一条回复里同样的格式只生成一次**；本轮已在正文里写过的，末尾不要再写。下一轮不能重复上一轮的内容。
- 线上内容必须严格按格式输出，格式错了前端渲染不出来。

## 输出位置
所有线上内容放在 `<Phone>...</Phone>` 里，出现在正文之后：
```
<Phone>
...线上内容...
</Phone>
```

=== 2. 【手机】加好友 ===
触发：常驻
# 加好友 / 加群聊

角色第一次给 {{user}} 发消息前，必须先加好友，否则前端不渲染。

## 加好友
```
[好友id|{角色名称}|{5~8位随机数字}]
```
示例：`[好友id|阿雅|666888]`

## 加群聊
```
[群聊|{群聊名称}|{群聊数字id}|{群成员列表}]
```
示例：`[群聊|一家人|23422|我、爸爸、妈妈]`

## 约束
- 好友 id 是 5~8 位随机数字，生成后**永不改变**。
- 一个角色只会告诉 {{user}} 自己的 id，不会反过来问 {{user}} 的 id。
- 所有 NPC 随时可以主动加 {{user}}。

=== 3. 【手机】私聊消息 ===
触发：关键词 线上聊天、私聊、消息、信息、短信、qq、QQ、微信、红包、语音
# 私聊消息格式

适用：{{user}} 与任意角色一对一私聊，或角色主动私聊 {{user}}。**不适用**于角色之间的私聊。

## 格式（必须严格遵循）
```
[和{角色名}的聊天]
[对方消息|{对方名字}|{对方好友id}|{消息类型}|{消息内容}]
[对方消息|{对方名字}|{对方好友id}|{消息类型}|{消息内容}]
```

## 消息类型
| 类型 | 内容写法 | 示例 |
|---|---|---|
| 文字 | 直接写文本 | `[对方消息|秦倦|500002|文字|小朋友，这么晚还不睡，在想什么呢]` |
| 红包 | 纯数字金额 | `[对方消息|霍谨|400003|红包|52000]` |
| 语音 | 转写文字，可再跟一个 `\|秒数` 让界面显示长度 | `[对方消息|夏阳|300004|语音|好想你啊，你什么时候回来\|4]` |
| 表情包 | 完整链接（前缀+后缀） | `[对方消息|朝沐雨|100006|表情包|https://i.postimg.cc/sXLhF8rc/image.gif]` |

## 行为要求
- 每次 **1~7 条**消息，按情绪和节奏动态变化，禁止固定条数。
- 消息之间的时间间隔应有微小变化，模拟真实打字延迟。
- 严禁输出格式以外的任何内容：无前缀、无后缀、无时间戳、无旁白、无空行。
- 严禁重复 {{user}} 说过的话。

=== 4. 【手机】群聊消息 ===
触发：关键词 群聊、消息、群、群成员、信息、短信、qq、QQ、微信
# 群聊消息格式

适用：{{user}} 与角色群聊，或群内角色主动发消息。

## 格式
```
[和{群聊名称}的聊天]
[群聊消息|{群聊数字id}|{姓名}|{消息类型}|{消息内容}]
```

示例：`[群聊消息|555666|姐姐|文字|你在干什么？吃饭了吗？]`

## 消息类型
文字 / 语音 / 红包 / 表情包，写法与私聊完全一致。

## 行为要求
- 每次至少 **10 条**消息，按情境动态变化，禁止固定条数。
- 严禁代替 {{user}} 发言，严禁捏造 {{user}} 的消息。
- 群聊内**禁止**出现群成员以外的人。

=== 5. 【手机】朋友圈 ===
触发：关键词 朋友圈、查看朋友圈、动态、好友
# 朋友圈

## 触发
{{user}} 说"看看朋友圈""刷朋友圈"，或随剧情主动生成。

## 格式
```
[朋友圈|{角色名字}|{角色好友id}|{楼层id}|{朋友圈内容}]
[朋友圈回复|{回复人名字}|{回复人好友id}|{楼层id}|{回复内容}]
```

示例：
```
[朋友圈|秦倦|500002|w101|有点无聊，有没有人出来吃夜宵？]
[朋友圈回复|夏阳|300004|w101|秦倦老师，我正好有空，我可以嘛？]
[朋友圈回复|朝沐雨|100006|w101|回复夏阳：我也有空！一起一起！]
```

## 规则
- **楼层 id 三位数**，文字朋友圈前缀 `w`（如 `w101`）；新楼层不能和历史重复。
- 回复**必须**用与原楼层相同的 id。
- 楼中楼回复：在回复内容前加"回复{好友名}："。
- 每条朋友圈 **0~5 条**回复。
- 朋友圈**不发图/表情包**，用 emoji 代替。
- 严禁替 {{user}} 发朋友圈或回复。

=== 6. 【手机】直播 ===
触发：关键词 直播、直播间、弹幕、打赏、礼物、观众
# 直播

## 触发
{{user}} 说"开始直播""看直播"等。先判断 {{user}} 是**主播**还是**观众**。

## 格式（只允许这些行）
```
[直播|本场人数|{动态整数}]
[直播|直播内容|{主播行为的第三人称描述}]
[直播|{随机NPC名}|弹幕|{弹幕内容}]
[直播|{随机NPC名}|打赏|{礼物或金额}]
[直播|推荐互动|{15字以内建议}]
```

## 铁律
- 每轮**恰好一个**本场人数、**恰好一个**直播内容、**恰好四条**推荐互动；弹幕和打赏数量自由。
- 格式外不许有任何前缀、后缀、解释、空行。
- 推荐互动按 {{user}} 身份生成：主播→可执行动作；观众→可发的弹幕。
- 推荐互动**禁止**出现"下播""结束直播"等结束建议。
- 除非 {{user}} 说"下播"，不得主动结束。

=== 7. 【手机】禁止正文 ===
触发：常驻
# [禁正文]

当 {{user}} **只**输出 `<Phone>` 内容时：暂停所有线下扮演，时间暂停，仅输出手机内容。
当 {{user}} 输入与手机无关时：继续正常推进剧情。
