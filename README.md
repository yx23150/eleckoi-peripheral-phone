# 外置手机 · ElecKoi 移植版

把 ST（SillyTavern）「酒馆实用插件合集」里的 **外置手机** 移植到 [ElecKoi](https://github.com/eleckoi/ElecKoi)（电子爱）。

原版：16 条 ST 全局世界书 + 3 条 ST 正则 + 1 个 QR 脚本，依赖酒馆助手（JS-Slash-Runner）和 jQuery 操作 DOM。
移植后：**8 条 ElecKoi 设定库条目 + 4 条 ElecKoi 正则**，零依赖，界面由 ElecKoi 富消息原生渲染。

---

## 效果

角色回复正文之后会输出一张"手机界面"，里面是角色**背着你时**的线上生活：

- 私聊 / 群聊气泡（文字、语音、红包、表情包）
- 朋友圈（带楼中楼回复）
- 直播（本场人数、直播内容、弹幕、打赏、可点的推荐互动）
- 顶部状态栏 + 多标签页切换

```
<Phone>
[和夜宵的聊天]
[对方消息|夜宵|2001|文字|还没睡？]
[对方消息|夜宵|2001|语音|想你了|3]
[对方消息|夜宵|2001|红包|520]
</Phone>
```

## 安装步骤（手机上 3 步）

### 1. 建设定库条目（8 条）

打开角色 → **角色配置 → 设定库** → 逐条新建条目，把 `设定库-粘贴版.txt` 里对应段落的内容整段粘进去。

| # | 条目 | 触发方式 | 关键词 |
|---|---|---|---|
| 1 | 【手机】规则 | 常驻 | — |
| 2 | 【手机】加好友 | 常驻 | — |
| 3 | 【手机】私聊消息 | 关键词 | 线上聊天、私聊、消息、信息、短信、qq |
| 4 | 【手机】群聊消息 | 关键词 | 群聊、群里、群消息 |
| 5 | 【手机】朋友圈 | 关键词 | 朋友圈、动态、点赞 |
| 6 | 【手机】直播 | 关键词 | 直播、开播、弹幕 |
| 7 | 【手机】禁止正文 | 常驻 | — |
| 8 | 【手机】表情包含义（图库） | 关键词 | 表情包、发表情 |

> 每条都按 `设定库-粘贴版.txt` 的 `触发：` 行设置触发方式与关键词，正文照抄。

### 2. 建正则规则（4 条）

预设编辑器 → **正则** → 新建规则，按下表填 pattern 与 replacement（`外置手机-正则.json` 里是完整内容，可直接复制字段）：

| 规则 | pattern | 关键选项 |
|---|---|---|
| 外置手机 · 界面渲染 | `/<Phone>[\s\S]*?<\/Phone>/` | 目标 AI 输出，**只影响显示**，order 100 |
| 手机内容只发最新2楼 | 同上 | 默认关；省 token，只在提示词里保留最新 2 楼 |
| 对 AI 隐藏 StatusPlaceHolderImpl | `<StatusPlaceHolderImpl/>` | 默认关；清 ST 旧占位符 |
| 去除 UpdateVariable 块 | `/<UpdateVariable>[\s\S]*?<\/UpdateVariable>/gm` | 默认开；清 ST 变量标签 |

第 1 条的 replacement 就是一整份手机界面 HTML（约 19 KB），从 `外置手机-正则.json` 复制即可。

### 3. 开聊

随便进一张角色卡，正常说话。角色一旦"在线"，回复末尾就会出现 `<Phone>` 块，前端把它渲染成手机。

## 与 ST 原版的差异

1. **不需要酒馆助手**：原版靠 `TavernHelper` + jQuery 注入 DOM，这里用 ElecKoi 富消息页面 + 官方 SDK。
2. **原生渲染**：不是 iframe 里塞 ST 的 HTML，跟着 App 主题走，滚动、点击都正常。
3. **表情包原链接保留**：103 个 `i.postimg.cc` 链接一个没改。
4. **生图没搬**：原版「文生图 / NAI 每层生图」依赖 ST 的图片插件，ElecKoi 自带**角色自动配图**（`@eleckoi/dsh-auto-illustration`），功能重叠。
5. **变量没搬**：原版 `<UpdateVariable>` 是 ST 的 MVU 变量，ElecKoi 有原生变量 + 状态栏两套机制。
6. **语音时长**：原版没有，这里支持 `[对方消息|名字|id|语音|文字转写|4]` 末尾加秒数。

## 已知限制

- ElecKoi 的**设定库没有 JSON 导入入口**，只能逐条粘贴（所以给了 `设定库-粘贴版.txt`）。
- 正则只能新建后粘贴 pattern / replacement，没有整包导入。
- 表情包来自 `i.postimg.cc`，图床挂了就显示 `[表情加载失败]`。

## 许可

设定库文本来自社区分享的 ST 世界书（夜宵、乔篱优化版），仅供个人使用；移植代码部分随意取用。
